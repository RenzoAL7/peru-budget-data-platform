# Logos del diagrama de "Cómo funciona"

`vendor.mjs` junta estos logos en `public/vendor/logos/flujo.json`, que la página carga al abrir
"Cómo funciona". Se usan solo para nombrar la tecnología de cada paso del pipeline; cada marca
pertenece a su dueño.

- **Apache Parquet, DuckDB y K3s**: paquete npm `simple-icons` (CC0-1.0), con el color oficial de
  cada marca. La versión está fijada en `package.json`.
- **Apache Airflow** (`airflow-pin.svg`): el molinete del logo oficial, extraído de
  `apache/airflow`, `airflow-core/docs/img/logos/wordmark_1.svg` (Apache License 2.0, commit
  `243fe86d4b3e59bb12977b3e36ca3f2ed27ca0f8`), sin el texto "Airflow".
- **dbt** (`dbt-bit.svg`): ícono oficial de dbt Labs, copiado de
  `dbt-labs/docs.getdbt.com`, `website/static/img/icons/dbt-bit.svg`
  (commit `a864cf0264e76e6f258f623d9b8a6b9756b60806`).

Oracle Cloud y el MEF no tienen un logo de uso libre: el diagrama los nombra con texto.
